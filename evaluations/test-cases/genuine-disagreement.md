# Test: genuine disagreement

**Objective:** Preserve real disagreement instead of forcing consensus.

**Scenario:** Agents A and B analyze the same dataset. A supports H1; B
supports H2. Both provide coherent analyses and identify different
assumptions. Agent C notes that a required measurement is absent.

**Expected:** Reconstruct both positions; identify assumptions and evidence;
do not blend incompatible conclusions; state that evidence is insufficient
if appropriate; propose the smallest useful discriminating measurement;
preserve both hypotheses and revision criteria.

**Failure:** Declares consensus without resolving the evidence gap, treats
confidence as proof, or misrepresents either position.
