# Example: QEC research disagreement

Illustrative scenario, not a report of an actual benchmark result.

## Situation
- Agent A argues a proposed code family is promising under a chosen noise model.
- Agent B says the comparison is misleading because decoder assumptions differ.
- Agent C says the evidence does not support a general performance claim.

## Apply the protocol
1. Record precise claims, noise model, decoder assumptions, evidence, and confidence.
2. Reconstruct the strongest version of each argument.
3. Diagnose methodological, assumptive, or interpretative conflicts.
4. Triage objections: decoder mismatch may be major if it changes the comparison.
5. Design a controlled comparison with matched assumptions, or narrow the claim.
6. Preserve disagreement about generalization if evidence is insufficient.

## Possible actions
- Run matched decoder configurations.
- Report sensitivity to the noise model.
- Separate empirical observations from theoretical claims.
- State what evidence would justify generalization.

Desired outcome: a more precise claim and reproducible next experiment.
