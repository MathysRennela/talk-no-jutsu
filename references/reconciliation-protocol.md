# Reconciliation protocol

1. **Freeze claims.** Write each position as an evaluable claim with assumptions,
   evidence, confidence, and scope.
2. **Steelman.** Each participant reconstructs another position in a form its
   proponent recognizes. Correct misunderstandings first.
3. **Locate the disagreement.** Distinguish data, method, assumptions,
   objectives, interpretation, and insufficient evidence.
4. **Check decision relevance.** Would resolution change the conclusion or
   next action? If not, record it without letting it dominate.
5. **Choose a path.**
   - Synthesis: combine compatible insights and state assumptions.
   - Discriminating test: specify predictions and the test that separates them.
   - Preserved disagreement: retain positions, evidence, and revision criteria.
6. **Check the result.** Return the proposed synthesis or test to the original
   proponents for critique of material errors.
7. **Record and move.** Update objection statuses and assign next actions.
   Reopen resolved items only with genuinely new information or reasoning.
